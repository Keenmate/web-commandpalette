# Building & testing

```bash
npm install
npm run dev              # examples hub + pages on http://localhost:12300
npm run build            # check:vars:strict → cem analyze → vite build (dist/)
npm run test:unit        # vitest (machine + helpers)
npm run test:e2e:install # once: Playwright chromium
npm run test:e2e         # Playwright (desktop + Pixel 7 projects)
npm run package          # build + npm pack
```

The same tasks are available through `make` (run `make` to list them): `make dev`, `make build`,
`make test`, `make kill-port` (frees ports 12300–12305), `make publish-dry`, `make publish-rc`
(the `rc` dist-tag; `latest` is untouched) and `make publish` (`latest`). The publish targets ask
for confirmation and always clean and rebuild `dist/` first. A pre-release version (`x.y.z-dev`,
`-rcNN`) must go out through `publish-rc`, because npm rejects it without a dist-tag.

Single tests: `npx vitest run test/unit/palette.test.ts`, `npx vitest run -t "context search"`,
`npx playwright test e2e/wizard.spec.ts`.

## Outputs

- `dist/web-commandpalette.js` (ESM), `dist/web-commandpalette.umd.js`, `dist/index.d.ts` —
  `@keenmate/web-components-core` is bundled; the palette CSS is inlined into the JS (shadow root).
- `custom-elements.json`, `web-types.json`, `vscode.html-custom-data.json`,
  `vscode.css-custom-data.json` — generated by `cem analyze` from the element's `static inputs` /
  `static events` tables and `component-variables.manifest.json`. Not committed.

## The CSS pipeline

`src/css/main.scss` `@use`s core's partials straight out of `node_modules/@keenmate/pure-admin-core`.
`scripts/shadow-css.mjs` compiles it with Sass (a Vite plugin — Vite's own Sass importer rejects the
bare `@import`s inside core because of package `exports`) and adapts the output to the shadow root:
fallback-less `var(--x)` reads get core's defaults as fallbacks, and `rem` becomes
`calc(N * var(--base-rem, 10px))`. `npm run check:vars` runs the same pipeline to validate the
manifest.

To pick up a new core palette: bump `@keenmate/pure-admin-core`, rebuild, run `check:vars`.
