# Documentation

Guides for `@keenmate/web-commandpalette`. (For the basics — what it is, install, quick start —
see the root [`README.md`](../README.md).)

- **[Usage](./usage.md)** — how the palette behaves (modes, keyboard), every property, attribute,
  method and event, the data shapes (`Command`, `Step`, `Context`, `Option`, `Result`), step
  pickers and branching, async search, result groups, favorites & recents, the confirmation, RTL,
  icons, labels and logging.
- **[Theming](./theming.md)** — the `--cp-*` / `--base-*` namespaces, `--base-rem` sizing,
  `--base-font-size-*`, the `--cp-*` knobs, replaceable icons, size presets, shadow parts.
- **[Examples](./examples.md)** — the example pages and recipes (open from a button, navigate on
  select, `fetch` search, server-loaded steps).
- **[Accessibility](./accessibility.md)** — the ARIA model, focus handling, keyboard, RTL, live
  announcements.

See also [`BUILD.md`](../BUILD.md) (building, testing, the CSS pipeline, publishing, the example-site
image) and [`IMPLEMENTATION_PLAN.md`](../IMPLEMENTATION_PLAN.md) (the original design spec and the
bugs that motivated it).
