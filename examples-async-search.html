AS01 · Scoped Context Search

Entering a context (:products or its alias :p, from the home screen, or with :p laptop) locks the input to ":products " and shows “Searching in Products”. An empty query never calls the provider: you get “Type to search Products” instead. Typing calls searchCallback({ contextId: 'products' }, query).

AS02 · Global Search

Free text first shows any command or context whose name, shortcut or alias matches, instantly and without calling the provider. It then appends searchCallback('global', query) results. Try “deploy” (a command, then server hits) or “mac”.

AS03 · Debounce & Abort

Provider calls wait search-debounce ms after the last keystroke. A newer query aborts the in-flight request through its signal, and its late result is dropped, so stale results never overwrite fresh ones. Raise the simulated latency and type quickly to see the aborts.

AS04 · Pagination

Results are split into pages of page-size in the browser. ← and → turn pages when the caret is at the edge of the input, with no new provider call. “item” returns 40 hits.
