BU01 · The Three-Line Setup

Mount one <web-command-palette> per page and give it commands, contexts and a searchCallback. That's a fully working palette. Press Ctrl/⌘+K, then type / for commands, : for contexts, or anything else for global search. 

palette.commands = [{ id: 'home', shortcut: '/home', name: 'Go home', hotkey: 'g h' }, …];
palette.contexts = [{ id: 'people', shortcut: ':people', aliases: [':p'], name: 'People' }];
palette.searchCallback = async (scope, query, signal) => fetchResults(scope, query, signal);

BU02 · Opening the Palette

open-key sets the key used with Ctrl/⌘ (clear it to disable the global hotkey). A command's hotkey: 'g h' runs it from anywhere while the palette is closed. These g-sequences are ignored while you type in a field. Hosts can also call open(), toggle() or openWith(query) to open it already filled in.

BU03 · Effect Events

The host performs the effect and the palette closes itself: cp-select for a search result, cp-complete when a wizard finishes, and cp-command for an instant command (one with no steps). cp-open and cp-close bracket every session.
