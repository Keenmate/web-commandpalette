Theming & Presentation

The palette is styled by pure-admin-core's own CSS. Theme it with --base-* and --cp-* variables, scale it with --base-rem, and pick a size preset or the phone sheet.

TH01 · Themes via CSS Variables

Every variable the palette reads falls back to pure-admin-core's default. Nothing is declared inside the shadow root, so a theme set on :root or any ancestor always wins. These presets set variables on <html>.

TH02 · Scale with --base-rem

pure-admin sizes everything in rem, assuming a 10px root. Inside the shadow root every Nrem is compiled to calc(N * var(--base-rem, 10px)), so the palette looks the same on any page. On a pure-admin page, set --base-rem: 1rem to follow the root font size.

TH03 · Size Presets

size="sm|lg|xl" sets width and results height together. For any other size, set --cp-width, --cp-results-max-height or --cp-offset-top yourself.

TH04 · Phone Fullscreen Sheet

With mobile-presentation="auto" (the default), touch phones get a fullscreen sheet with a close bar, which stays above the on-screen keyboard. A narrow desktop window keeps the floating dialog. Force fullscreen to preview the sheet here.
