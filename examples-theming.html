TH01 · Themes & Sizes

How far you can take the palette without touching its CSS. Each theme below is its own palette instance, styled only from the outside through the shared --base-* variables, the palette's --cp-* knobs (icons included) and the ::part() hooks (container, input, results, footer, backdrop). The CSS under each card is read back from this page's stylesheet, so it's exactly what's applied. Try /deploy to see the wizard and the confirmation, and Ctrl/⌘+D for the star icon.

The rules here are scoped to one instance (#theme-neon). Nothing is declared inside the shadow root, so the same rules on :root or any ancestor theme every palette on the page, and anything you don't set falls back to pure-admin-core's default.

The size switches below apply to every palette here, so any theme can be tried at any size. --base-rem scales everything: inside the shadow root every Nrem is compiled to calc(N * var(--base-rem, 10px)) (on a pure-admin page set --base-rem: 1rem to follow the root font size). size presets set width and results height together; for anything else use --cp-width, --cp-results-max-height and --cp-offset-top. mobile-presentation="auto" gives touch phones a fullscreen sheet above the on-screen keyboard; force fullscreen to preview it here.
